# Evaluation Results

This directory holds timestamped evaluation outputs generated by `scripts/run_retrieval_eval.py`.

Each run generates a subfolder `results/<timestamp>_<retriever>/` containing:
- `results.json`: Detailed per-question metrics, ranks, retrieved chunks, configuration snapshot, and git SHA.
- `summary.md`: Human-readable summary table with mean retrieval metrics, category breakdown, source-type distribution, and the 5 worst-performing queries.

Output runs in this directory are gitignored.
